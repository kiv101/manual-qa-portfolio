# Manual QA Portfolio: E-Commerce Platform Testing

## 📌 Описание проекта
В данном репозитории представлено портфолио ручного тестировщика (QA Manual). В качестве объекта тестирования выбрана учебная платформа интернет-магазина (Веб-сайт + Мобильное приложение).

**Цель проекта:** Продемонстрировать навыки анализа требований, составления тестовой документации, применения техник тест-дизайна и локализации дефектов.

---

## 🛠️ Окружение (Test Environment)
Тестирование проводилось на следующих платформах:
* **Web:** Google Chrome (v122.0), Yandex Browser (v24.1) / ОС: Windows 11.
* **Mobile:** Смартфон Xiaomi Redmi Note 12 (Android 13, MIUI 14), приложение (v2.4.1).

---

## 📐 Примененные техники тест-дизайна
При составлении тест-кейсов использовались:
1. **Эквивалентное разделение и анализ граничных значений** (для полей ввода: логин, промокоды, количество товара).
2. **Таблица принятия решений (Decision Table)** (для проверки условий оформления заказа в зависимости от типа пользователя и скидок).
3. **Предугадывание ошибки (Error Guessing)** (ввод спецсимволов, пустые поля, прерывание интернет-соединения).
